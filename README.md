# AccessCraft SoD Analyzer — downloads

This repository holds the released builds of the AccessCraft SoD Analyzer. It contains no source code.

## Browser edition

Nothing is installed: a folder and a browser.

1. Open **Releases**, pick the latest `browser-<date>` release and download `AccessCraft-SoD-Analyzer-Browser-<date>-index-only.zip`.
2. Unzip it anywhere.
3. Open `index.html` in Chrome or Edge.
4. Enter your licence key when asked. The page shows the Reference ID to send when requesting a key.

Your data stays in the browser on your own computer. Use **Save to file** in the sidebar to keep a copy of your workspace.

The "Source code" files GitHub lists under each release contain only this page.

## Desktop edition (Windows)

Installed on the computer; for larger systems.

1. Open **Releases** and pick the latest `desktop-<version>` release.
2. Download one of:
   - `AccessCraft.SoD.Analyzer.Setup.<version>.exe`: the installer
   - `AccessCraft.SoD.Analyzer.<version>.msi`: the same as an MSI package, for managed computers
   - `AccessCraft.SoD.Analyzer.Portable.<version>.exe`: runs without installing
3. The files are not digitally signed, so Windows shows an "unknown publisher" notice: choose **More info**, then **Run anyway**.
4. Enter your licence key when asked.
