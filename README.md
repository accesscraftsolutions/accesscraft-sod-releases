# AccessCraft SoD Analyzer — downloads

This repository holds released builds of the AccessCraft SoD Analyzer: segregation-of-duties and critical-access analysis for SAP. It contains no source code.

## Demo version

No licence key, nothing to install: a folder and a browser.

1. Open **Releases** and download the latest `AccessCraft-SoD-Analyzer-Demo-<date>.zip`.
2. Unzip it anywhere.
3. Open `index.html` in Chrome or Edge.

The demo comes with a made-up example company that is already loaded and analysed, so you can try every screen: the Dashboard, the reports, Risk Analysis, Remediation, Simulation, mitigating controls and the licence classification.

**AccessCraft_Demo_Guide.html**, next to the zip on each release, is a short walk through the demo with pictures. The same guide is inside the zip and in the demo's left menu.

Everything runs inside your browser, on your own computer. No data leaves it.

## Full version

The demo works with its example company only. The full version analyses your own SAP systems with the complete ruleset. It is available as a browser edition (like the demo) and as a Windows desktop application, and it needs a licence key.

The full version is provided to licensed customers directly. To ask for it, or for a licence, write to **contact@accesscraftsolutions.com**.
