# AccessCraft SoD Analyzer — downloads

This repository holds released builds of the AccessCraft SoD Analyzer. It contains no source code.

## Demo version

A demo version will be published here under **Releases**. It needs no licence key and nothing is installed: unzip it and open `index.html` in Chrome or Edge. It comes with a made-up example company, so you can try every screen: the Dashboard, the reports, Remediation, Simulation and the licence classification.

## Full version

The full version analyses your own SAP systems. It is available as a browser edition (a folder and a browser, nothing installed) and as a Windows desktop application, and it needs a licence key.

The full version is provided to licensed customers directly. To ask for it, or for a licence, write to **contact@accesscraftsolutions.com**.
